# Invoker Trainer

A Dota 2 Invoker practice game, inspired by [invoker-game.com](https://invoker-game.com/).
Invoke spells as fast as you can, with rebindable keys (including Spell 1 / Spell 2), an
optional **Invoke + Cast** mode, a custom number of spells per run, and per-spell splits.

Play: https://m-tse.github.io/invoker/

## Develop

```sh
npm install
npm run dev
```

Pushes to `main` build and deploy to GitHub Pages via `.github/workflows/deploy.yml`.
